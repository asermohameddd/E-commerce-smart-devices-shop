# Smart Devices E-commerce Website

A modern and responsive e-commerce website for smart devices, built using HTML and CSS.

The website provides a clean and user-friendly interface for browsing smart devices and viewing product details (Available for Samsung Galaxy A17 5G only).

## Features:

- Fully Responsive Design optimized for different screen sizes.
- Modern and clean user interface.
- Product showcase with detailed specifications(Available for Samsung Galaxy A17 5G only).
- Product details page(Available for Samsung Galaxy A17 5G only).
- Shopping cart page(Designed as a simulation for a real E-commerce website but not an actual cart).
- Navigation between different website pages.
- Clean layout built using CSS Flexbox.
- User-friendly design for an e-commerce experience.

## Technologies Used:

- HTML5
- CSS3
